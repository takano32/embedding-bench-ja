## 結論

- **埋め込みの質（正解が上位に来るか）**: bge-m3 と Sarashina の差は、この標本では測れなかった。
  - 200 問の全体で、正解が1位に来る割合は Sarashina 83.4%、bge-m3 81.9%（差 +1.5 点、95% 区間 −4.5〜+7.5）。上位10に正解がある割合は 97.5% と 96.0%（差 +1.5、−1.5〜+4.5）。
  - 区間が 0 をまたがない差は2つだけ: 実メッセージ（T 84 問）の上位5・上位10の適合率が Sarashina で +6.5 点・+6.1 点（Jev のラベル）。言い換え型の既知の1件（K 57 問）で、上位3に正解がある割合が +7.0 点（区間の下端が 0.0）。
  - ただし本流が読んで付けたラベル（32 問）では、同じ問いで差が出なかった（1位率は 73.3% と 73.3%、上位5に正解ありは 90.0% と 96.7%）。Jev の「関連あり」が本流の基準より広い（下記）ので、T の適合率の差は Jev の基準に依る可能性がある。
  - 「替えるべきか」には、質だけでは答えが出ない。どちらにも倒せない。
- **遅延**: 問いの埋め込みは Sarashina の中央値 64 ms（最大 278 ms）、bge-m3 の中央値 214 ms（最大 695 ms、本番が同居する 2 コアの CPU）。文書側（抜き取り 24 件）は Sarashina の中央値 61 ms、bge-m3 の中央値 1,071 ms。Sarashina のほうが速く、箱の CPU を使わない。429 も 20 秒超の遅延も出なかった（20 回/分）。
- **足切り（0.70 と 0.74）**: 動かす理由は見つからなかった。必要な記憶は落としていない。
  - K で、問いの元にした記憶そのものが 0.70 と 0.74 を通る割合は 115/116（99.1%、Wilson 95% 区間 95.3〜99.8%）。0.78 まで同じで、0.80 で 89.7% に落ちる。
  - 関連あり（Jev）のうち閾値以上の割合は、0.70 で全体 99.8%、0.74 で全体 94.1%（K 97.7%、T 93.8%）。0.76 で 80.0%、0.78 で 52.3%。
  - 本流のラベル（32 問の人手プール、浅い）では 0.74 で 99.2%、0.76 で 92.2%。
- **ただし、この足切りは混入を止める役を、ほぼしていない。** 全記憶をコサインで並べた上位 60 のうち、0.70 に当たるのは平均 0.5 件（当たる問いは 1.5%）、0.74 でも 3.5 件（12%）。関連なしを通す割合は 0.70 で 93%、0.74 で 71%（深いプール）。絞っているのは Jev で、床は「明らかに遠い記憶を Jev に渡さない」程度の安全弁になっている。
  - 床を 0.76 に上げると、上位 12 の件数が 12 に満たない問いが 11.5%（0.74 は 2.5%）。0.78 だと 29% で、上位 12 に関連ありが1件でもある問いが 97% から 94% に減る。上げて絞るなら、この取りこぼしと引き換えになる。

提案（本番は変えていない。決めるのは takano32）:
1. 足切りは現状維持でよい。動かすなら下げる方向（0.70 未満）は不要、上げる方向は 0.76 以上で取りこぼしが出る。
2. 埋め込みの入れ替えは、質を理由にはできない。続ける理由は遅延と箱の CPU、続けるリスクは 60 回/分の共有枠、外部 API への依存、規約（個人を識別できる情報の入力禁止）。戻す理由は、この結果の範囲には無い。
3. この結果は埋め込みだけの順位。本番はリランカー（`sarashina3-rerank`）を通すので、本番の最終的な並びの質は別に測る必要がある。

## ついでに分かったこと

- Jev の「関連あり」は、本流が読んだ基準より T で広い。同じ 293 組で、Jev は 58.7%、本流は 30.7% を関連ありとし、本流だけが関連ありとしたのは 2 組、Jev だけは 84 組（κ 0.45）。K では 95.8% 一致（κ 0.82）。受信時のフックの Jev（p>=0.5）が通す記憶は、本流の基準より広めに出ている可能性がある（フックの Jev 判定には履歴が付くが、ここでは付けていない）。
- Jev は同じ入力を並びだけ変えて 2 回撃つと 94.4% 一致（κ 0.86）。判定の揺れは小さいが、0 ではない。

## 偏りと限界（結論を読むときの注意）

- 問いは K が元の記憶から作った問いで、埋め込みに有利に出やすい（`docs/method.md`）。言い換え型（K 57 問）でも、書き手は元の文を読んでいる。T は元の文を見ずに作った（本番の受信そのもの）が、「関連あり」の基準が緩く、1問あたり関連ありが多い（中央値 21 件）ので、上位に来るかの指標は天井に近い。
- 上位10に正解がある割合は両モデルとも 96〜98% で、差が出る余地が小さい。難しい問い（埋もれた1件を探す）は K の一部しか含まない。
- 本流が付けたラベルは 32 問（偏りを避けて乱数で選んだ）。区間が広く、モデル間の差は検出できない。付けたのは 1 人（本流）で、2 人目はいない。
- 関連ありの数え方はプールの内側。深いプールでも各モデルの上位 100 の外は数えていない。閾値の再現は上限寄り。
- 記憶は bank nilkani06 の全部（管理チャンネルからの検索と同じ条件）。本番はチャンネルの印で絞るので、他のチャンネルの受信では候補の顔ぶれが違う。
- 本番の recall（全文検索、グラフ、リランカー、observation 優先）は再現していない。ここは「埋め込みのコサインだけ」の順位。
